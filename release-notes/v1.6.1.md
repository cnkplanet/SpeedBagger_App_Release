# SpeedBagger 1.6.1 업데이트 안내

| 항목 | 내용 |
|---|---|
| 앱 | v1.6.0 → v1.6.1 |
| 배포일 | 2026-10-01 |

## 1. 포장 작업 화면

**합포 화면이 단포와 같은 모양으로 바뀝니다.**
- 바코드 입력창, 운송장번호, 총주문/총실적/차이, 보조프린터·재발행 버튼 배치가 단포와 동일해집니다.
- 우측 상단에 오늘 완료 건수가 표시됩니다. 화면을 켜 둔 채 자정이 지나면 자동으로 오늘 기준으로 다시 집계됩니다.
- 합포 화면의 「배송처리」 버튼은 없어집니다. 수동 배송처리는 이력 화면의 「배송처리」 또는 자동 발송 스케줄로 진행합니다.

**합포 상품 검수 시 수량을 음성으로 읽어줍니다.**
- 같은 상품을 스캔할 때마다 "일, 이, 삼…" 으로 누적 수량을 읽어줘 화면을 보지 않아도 몇 개째인지 알 수 있습니다. 열 개를 넘으면 다시 "일" 부터 셉니다.

**완료 건수와 출력 건수를 구분해서 보여줍니다.**
- 단포 진척 배너와 합포 완료 배지에서 "완료" 는 배송처리까지 끝난 건만 셉니다. 라벨만 나가고 아직 배송처리 전인 건은 「출력 N」 으로 따로 표시되며, 출력 건이 없으면 항목이 보이지 않습니다.
- 작업완료 이력에서 출력 상태 행은 연한 주황 배경으로 표시됩니다.
- 작업완료 이력은 최근 50건만 보여줍니다. 처리량이 많은 날 화면이 느려지던 문제가 줄어듭니다.

## 2. 배송처리 실패 시 동작 변경 (중요)

지금까지는 라벨이 출력된 뒤 WMS 배송처리가 실패하면 주문이 "대기" 로 돌아가, 자료정리에 삭제되거나 재스캔 시 같은 라벨이 또 나가는 일이 있었습니다.

- 이제 배송처리에 실패해도 주문은 **"출력" 상태로 보존**되고, 화면에 "배송처리 실패. 출력 상태로 저장되었습니다. 이력 화면에서 배송처리해주세요." 라고 안내합니다.
- 보존된 건을 다시 스캔하면 "이미 출력된 주문입니다. 배송처리는 이력 화면에서 진행해주세요." 로 막혀 라벨이 중복 출력되지 않습니다.
- 이 건은 이력 화면에서 배송처리합니다 (아래 3번).

## 3. 이력 화면

**「배송처리」 확인창에 범위와 건수가 나옵니다.**
- "조회조건과 상관없이 현재 출력상태인 모든 주문이 배송처리됩니다. 출력상태인 주문은 모두 N건입니다." 로 안내합니다. 0건이면 확인창 없이 "출력상태인 주문이 없습니다." 만 뜹니다.
- 일부만 실패하면 "M건 완료, F건 실패. 실패 건은 출력 상태로 남아 있으니 다시 배송처리해주세요." 로 알려줍니다.

**상세창에서 한 건만 배송처리할 수 있습니다.**
- 작업구분이 '출력' 인 주문의 상세창에 빨간 「배송처리」 버튼이 생깁니다.
- WMS 쪽은 이미 배송완료인데 우리 쪽만 출력 상태인 건은 "이미 서버는 배송완료처리 상태이므로 상태를 배송완료로 변경하겠습니다." 안내 후 상태만 맞춥니다. 전에는 이런 건이 영원히 출력 상태로 남았습니다.

**자료정리에서 작업 중인 주문은 지우지 않습니다.**
- 최근 30분 안에 스캔한 주문은 삭제 대상에서 빠지고, "(작업 중 N건은 제외)" 라고 안내합니다. 합포 검수 중에 다른 포장기가 자료정리를 실행해 주문이 사라지던 문제가 해결됩니다.

**합포 이력에서 취소된 상품 행은 보이지 않습니다.** 포장하지 않은 상품이 이력에 섞여 나오지 않습니다. 주문 자체가 취소된 건은 상품별 취소 사유를 그대로 볼 수 있습니다.

## 4. 스캔 판정과 송장 인쇄

- **취소와 보류가 동시에 걸린 주문은 취소로 판정**됩니다. 전에는 보류로 안내되어 작업자가 다시 시도하는 일이 있었습니다.
- **OneWMS 부분취소 주문**: 합포에서 일부 상품만 취소된 경우, 취소 상품은 빼고 나머지만 포장 대상으로 진행합니다. 전체 취소 건은 취소로 안내합니다. 전에는 이 건이 보류로 묶이거나 취소 상품까지 포장 대상에 섞였습니다.

## 5. 주문 수집

- 수집 중 WMS 가 잠시 응답하지 않을 때 자동으로 재시도하고, 수집 결과의 실패 건수가 정확하게 표시됩니다.
- **Sellmate WMS 연동이 서버에 추가**되었습니다. 웨이브(피킹 단위) 기준 수집도 지원합니다. 다만 앱에서 창고·웨이브를 선택하는 화면은 아직 없어 현장 사용은 후속 업데이트 이후 가능합니다.

## 6. 녹화 기능 (영상 저장 사용 업체)

- **앱 업데이트 용량이 크게 줄어듭니다.** 녹화 프로그램을 앱에 내장하지 않고, 영상 저장을 켠 PC 에서만 최초 1회 약 63MB 를 자동으로 내려받습니다. 녹화를 쓰지 않는 업체는 다운로드가 없습니다.
- 다운로드 중에는 하단바에 진행률이 보이고, 그동안 스캔하면 "녹화를 위한 실행 파일을 다운로드 중입니다. 완료된 후 다시 스캔해주세요." 로 안내합니다.
- **다운로드가 3회 실패하면 영상 저장이 자동으로 꺼집니다.** 원인(네트워크, 저장 공간 부족 등)과 함께 안내하고, 다음 스캔부터는 정상 진행됩니다. 다시 켜려면 설정 > 녹화에서 켜면 됩니다. 인터넷이 막힌 창고에서 포장 전체가 멈추지 않도록 한 조치입니다.
- 설정 > 녹화 화면에 다운로드 진행률, 실패 원인, 「다시 시도」 버튼이 추가됩니다.

## 7. 관리자

- 승인요청 메일에 참조(CC) 수신자를 지정할 수 있습니다.
- 다른 파트너의 주문을 조작하거나 수집할 수 없도록 서버 검증이 강화되었습니다. 정상 운용에서는 체감되는 변화가 없습니다.
